## Regras do Demo Any%: Cronometragem, Tamanho da Equipe e Prova

A categoria rastreada é **Demo Any%**. Seu objetivo é concluir a demo o mais rápido possível, e o ranking usa IGT como método de cronometragem. Isso significa que o tempo registrado se baseia no cronômetro interno do jogo, e não em um cronômetro externo.

Os requisitos verificados são diretos:

- **Categoria:** Demo Any%.
- **Objetivo:** Concluir a demo o mais rápido possível.
- **Cronometragem:** Tempo no jogo, ou IGT.
- **Tamanho da equipe:** Até quatro jogadores.
- **Prova:** As runs exigem vídeo e verificação.
- **Escopo:** Os dados disponíveis da API do Speedrun.com não estabelecem recordes para nenhuma categoria além de Demo Any%.

Essas regras tornam a categoria fácil de entender, mas rígida para enviar. Uma conclusão rápida sem a prova em vídeo exigida não é uma run verificada.
